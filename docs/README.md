# Woven Matter documentation

Start with a local agent, then add remote workspaces and other tools as you need
them. These guides describe the app on `main`; an older installed release may
have different controls. Check [release notes](https://github.com/wovenmatter/wovenmatter/releases)
for changes in your version.

## Start here

1. [Getting started](guide/getting-started.md) — install the app and start a chat.
2. [Agent setup](guide/agents.md) — choose, install, enable, and connect agents.
3. [Conversations](guide/conversations.md) — organize and continue your work.

## Your workspace

- [Workspaces and storage](guide/workspaces.md) — where files and app records live.
- [Remote workspaces](guide/remote-workspaces.md) — work on Linux through the Mac app.
- [Notes and data](guide/notes-and-data.md) — notes, spreadsheets, HTML, and database folders.
- [Scheduled work and usage](guide/schedules-and-usage.md) — Cron Jobs, Calendar, and Usage.
- [Troubleshooting](guide/troubleshooting.md) — setup, connection, and data problems.
