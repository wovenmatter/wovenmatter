# Agent setup

Woven Matter runs Pi Durable, Codex, Claude Code, Grok Build and OpenCode. Use
the installations and provider accounts you already have, or install harnesses
from Settings. Models, sign-in and controls depend on the harness.

A **harness** is the software that runs the agent. A **provider** supplies the
model and account access. Pi Durable is included with Woven Matter; see
[Pi Durable](default-agent.md).

## Set up a harness

1. Open **Settings → Agents** and choose the harness. For another machine, open
   it in **Settings → Workspaces** and choose the harness under **Agents**, or
   choose **Set up harnesses** there.
2. If the harness is missing, choose **Install** and review the installer before
   confirming.
3. Choose **Sign in** on the harness's page if its account is not connected,
   and follow the steps shown. **Remove account** signs the harness out.
4. Choose **New chat** and select the agent.

Each machine has its own installations and sign-ins. Harnesses keep their own
sign-ins; Woven Matter does not copy them between machines.

## Harness settings

Each harness's page in **Settings → Agents** shows its account, its software,
and **Defaults for new chats**. OpenCode also has its own model choices;
configure its provider accounts through OpenCode.

Use **Check for updates** or **Update** in the harness's **Software** row.
Finish the chats that use a harness before updating it.
**Settings → Updates** lists every harness on every machine and updates them
together; see [Updates](updates.md).

**Settings → General → Sidebar sections** shows or hides the local and remote
workspace sections of the sidebar.
